# `panda setup`

Initialize `~/.pandabot/panda.json` and the agent workspace.

Related:
- Getting started: [Getting started](/start/getting-started)
- Wizard: [Onboarding](/start/onboarding)

## Examples

```bash
panda setup
panda setup --workspace ~/panda
```

To run the wizard via setup:

```bash
panda setup --wizard
```
